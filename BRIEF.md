# BRIEF — mercurius-search

Поиск в интернете для агентов на AMPHP v3 за одним интерфейсом: запрос и лимит на входе, страницы (заголовок, адрес,
фрагмент, номер) и, если поставщик его пишет, краткий ответ — на выходе. Поставщики: SearXNG, Brave Search API, Tavily и
модель OpenRouter с веб-плагином; запасной порядок и кеш. Пакет — часть Меркурия (`opencck/mercurius`), подключается
сабмодулем в `packages/search/` и не зависит от приложения.

## Назначение и границы

В пакете:

- интерфейс `SearchProvider` и типы результата;
- четыре поставщика: HTTP-запрос, разбор ответа, ошибки без ключей;
- `FallbackSearch` — поставщики по порядку до первого успешного;
- `CachedSearch` — ответы в памяти на время;
- расход вызова модели у поиска через модель (`SearchUsage`).

В приложении остаётся:

- какие поставщики настроены и в каком порядке (`SEARCH_PROVIDERS`, `src/Infrastructure/Config/SearchSettings.php`),
  модель поиска (`WEB_SEARCH_MODEL`), ключи;
- инструмент `web_search` (`src/App/Agent/Tool/Web/WebSearchTool.php`): выбор поставщика агентом, обёртка результата
  как недоверенных данных, запись расхода в `llm_calls` и бюджет запуска;
- чтение страниц (`web_read`) и браузер — это не поиск.

## Устройство

| Класс / каталог | Что делает |
|-----------------|------------|
| `SearchProvider` | `name()` и `search(string $query, int $limit = 5, ?Cancellation): SearchResult` |
| `SearchResult` | Поставщик, страницы `SearchHit`, краткий ответ, расход `SearchUsage`; `toText()` — текст для модели; `withoutUsage()` |
| `SearchHit` | Одна страница: заголовок, адрес, фрагмент, номер |
| `SearchUsage` | Расход вызова модели: модель, входные и выходные токены, стоимость, если поставщик её назвал |
| `SearchException` | Ошибка поиска; ключей в сообщении нет |
| `FallbackSearch` | Список поставщиков (не пустой); при `SearchException` пробует следующего, при отмене останавливается; имя — имена через `>` |
| `CachedSearch` | Декоратор: ответ живёт `ttl` (600 с), не больше `size` (200) записей, старые вытесняются; ключ — лимит и запрос без регистра и лишних пробелов; ошибки не кешируются |
| `Provider/SearxngProvider` | Свой сервер SearXNG: `/search?q=&format=json`, адрес сервера в конструкторе |
| `Provider/BraveProvider` | Brave Search API, ключ в `X-Subscription-Token` |
| `Provider/TavilyProvider` | Tavily: `POST /search` с ключом на предъявителя; умеет краткий ответ |
| `Provider/OpenRouterProvider` | Модель OpenRouter с веб-плагином: ответ и страницы из `url_citation`, расход вызова в `SearchUsage` |
| `Internal/Json` | Один JSON-запрос с таймаутом (30 с на передачу и тишину); сбой, не-200 и не-JSON — `SearchException` |

## Решения

- **Один интерфейс на всех поставщиков:** агент выбирает поставщика по имени, а `FallbackSearch` и `CachedSearch`
  сами реализуют `SearchProvider` и складываются как декораторы.
- **Устройство — по образцу поставщиков поиска hermes** (`agent/web_search_provider.py`, `plugins/web/*`); взятое
  отмечено ссылками `ref:` в коде поставщиков и кеша.
- **Поиск через модель сообщает расход:** такой поиск — вызов модели запуска, приложение пишет его в учёт и бюджет.
- **У ответа из кеша расхода нет:** вызов уже посчитан, когда ответ попал в кеш, — повторный учёт его задвоил бы.
- **Ошибки не кешируются:** временный сбой поставщика не должен держаться десять минут.
- **Запасной порядок останавливается при отмене:** отменённый запрос не уходит следующему поставщику.
- **Таймаут на каждый запрос** (30 с): зависший поставщик не держит запуск агента.
- **Ключи — `#[SensitiveParameter]`,** в сообщения ошибок не попадают; в ошибке — только имя поставщика и вид сбоя.
- **Сеть выбирает вызывающий:** поставщики принимают любой `Amp\Http\Client\HttpClient`.

## Проверки

- `composer check` — PHPUnit, PHPStan (уровень `max`), Psalm (`errorLevel="1"`); тесты без сети, группы
  `integration` в пакете нет.
- CI (`.github/workflows/ci.yml`): одна задача, PHP 8.2 (другая версия — вручную через `workflow_dispatch`), push и
  pull request в `master`, изменения только в `*.md` не запускают, `cancel-in-progress`, кеш Composer и анализаторов,
  10 минут; без сети и секретов.
